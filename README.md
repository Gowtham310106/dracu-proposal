## 🚀 Instant Vercel Deployment

This project is **100% static and zero-config ready for Vercel**.

### Option 1: Deploy with Vercel CLI (Fastest)

```bash
# 1. Open terminal in this folder
npx vercel

# 2. For instant production deployment:
npx vercel --prod
```

### Option 2: Deploy via Vercel Dashboard (Git)

1. Push this folder to a GitHub, GitLab, or Bitbucket repository.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the repository.
4. Framework Preset: Select **Other** (Root directory `./`).
5. Click **Deploy**. Your site will be live on a fast global CDN with HTTPS within seconds.

## 🛠️ Local Development & Preview

To run locally:

```bash
# Using Python
python -m http.server 3000

# OR using Node.js
npx serve .
```

Open `http://localhost:3000` in your browser.

- `index.html` — Semantic quotation portal with OpenGraph tags and print structure.

- `vercel.json` — Vercel caching, routing, and HTTP security headers.
- `package.json` — Standard npm configuration for Vercel deployment detection.
